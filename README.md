# Calculator

A simple calculator web application built with HTML, CSS, and JavaScript.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear button
* Interactive display
* Button-based input
* Works directly in the browser

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
CALCULATOR-PROJECT/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Use the calculator buttons to perform calculations.

## What I Learned

While building this project, I practiced:

* HTML structure
* CSS styling
* JavaScript variables
* DOM manipulation
* Connecting JavaScript to HTML
* Handling button clicks
* Updating values on the calculator display

## Purpose

This project was built to practice my beginner web development skills and understand how HTML, CSS, and JavaScript work together to create an interactive web application.
